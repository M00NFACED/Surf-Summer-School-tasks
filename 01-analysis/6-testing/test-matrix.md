# QA Test Matrix — MVP

## 1. Метаданные

- Проект: Surf / клиент «Вертикаль»
- Этап: QA и стабилизация MVP
- Дата: 2026-09-25
- Контракт: `01-analysis/api/openapi.yaml`
- Трассируемость: BR-001, BR-003, BR-004, BR-005, BR-007, BR-013; FR-001, FR-002, FR-004, FR-005, FR-006, FR-008; NFR-001, NFR-003, NFR-004, NFR-005, NFR-007; SCR-001…SCR-005

## 2. Окружение и данные

| Параметр | Значение |
|---|---|
| Client | Compose Multiplatform, Android debug APK и desktop JVM |
| Backend | Локальный Go/PostgreSQL fixture-набор или внешний Contract Stub |
| Auth | OTP: 6 цифр; ответ request-code `202`; verify-code `200` |
| Время | Server time для дедлайна BR-007; тесты не используют только часы устройства |
| Offline | Отключение сети после успешного чтения расписания |
| UUID | Канонический 8-4-4-4-12 hex, включая version/variant `0` |

## 9. Автоматизация и результат

- `.\gradlew :client:shared:jvmTest` — unit/mapper/usecase/storage проверки.
- `.\gradlew :client:androidApp:assembleDebug` — Android debug APK.
- Manual device/emulator run и два параллельных HTTP-запроса к внешнему backend должны выполняться в QA-окружении; при отсутствии backend device-проверки остаются pending.
