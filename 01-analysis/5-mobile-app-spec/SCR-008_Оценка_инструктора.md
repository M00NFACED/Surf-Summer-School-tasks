# SCR-008 — Оценка инструктора

## 1. Метаданные

| Поле | Значение |
|---|---|
| ID | `SCR-008` |
| Название | Оценка инструктора |
| Роль | Клиент |
| Тип | Bottom Sheet поверх `SCR-007` |
| Маршрут | `modal:booking-rating` |
| Точка входа | Завершённая неоценённая бронь на `SCR-006` или `SCR-007` |
| Связанные требования | `BR-009`, `FR-010`, `NFR-003`, `NFR-005`, `NFR-006`, `US-008`, `UC-006` |
| Версия | 1.0.0 |
| Приоритет | Should |

## 2. Цель и пользовательский сценарий

- Цель: позволить Клиенту оставить одну оценку инструктору от 1 до 5 звёзд после фактически завершённой тренировки.
- Основной сценарий: Клиент открывает Bottom Sheet, выбирает оценку, подтверждает отправку, после HTTP 201 шторка закрывается, а `SCR-007` обновляет статус.
- Условия доступа: `booking.status = completed`, `booking.rating` отсутствует, `booking.id` принадлежит текущему Клиенту.
- Результат: сохранена ровно одна оценка; повторная отправка заблокирована.

Обязательные элементы:

- Bottom Sheet с контекстом инструктора и брони.
- Пять доступных звёзд без возможности выбрать 0.
- Disabled submit до выбора.
- Loading, Error 400/401/409, Offline и Forbidden.
- Закрытие без изменения данных и обновление `SCR-007` после успеха.

## 4. Состояния экрана

| Состояние | Условие | Отображение | Действие клиента |
|---|---|---|---|
| Initial | Бронь завершена и не оценена, шторка открыта | Контекст, пять звёзд, submit disabled | Выбрать оценку |
| Loading | Отправляется rating-запрос | Spinner, звёзды read-only, submit disabled | Дождаться |
| Success | API вернул HTTP 201 | Краткое подтверждение, закрытие шторки, обновление `SCR-007` | Вернуться к деталям |
| Empty | Оценка ещё не выбрана | Подсказка «Выберите от 1 до 5 звёзд», submit disabled | Выбрать значение |
| Error | API вернул 400, 401, 409 или 503 | Понятное сообщение, шторка остаётся открытой | Повторить, войти или закрыть |
| Offline | Нет сети | «Оценка отправится после восстановления сети», submit disabled | Восстановить сеть |
| Forbidden | Бронь не завершена, отменена, уже оценена или чужого клиента | Шторка не открывается; на `SCR-007` показывается причина | Вернуться к деталям |

## 5. Взаимодействие с API

| Вызов | Endpoint / метод | Назначение | Перед вызовом | Обработка ответа | Обработка ошибки |
|---|---|---|---|---|---|
| API-RATING-001 | `POST /bookings/{id}/rating` | Сохранить одну оценку инструктору | Bearer-токен; `booking.status = completed`; rating отсутствует; `score` 1–5 | `201 Rating`: обновить `SCR-007`, закрыть Bottom Sheet | `400`: не завершена/невалидный score; `401`: вход; `404`: бронь не найдена; `409`: уже оценена; `503`: Retry |

Требования к обработке:

- Проверять диапазон 1–5 и целочисленное значение до отправки.
- Не создавать локальный рейтинг до HTTP 201.
- Один активный rating-запрос; повторное нажатие блокируется.
- При 409 показать сохранённую оценку и закрыть/заблокировать submit без второй записи.
- При 403/неподходящем статусе не отправлять запрос, даже если шторка была открыта до обновления.
- При неоднозначном сетевом ответе сначала обновить `GET /bookings/my` и проверить `booking.rating`.

## 6. Валидация и правила

- `booking_id` — UUID текущей брони.
- Оценка доступна только после `status = completed`.
- `score` — целое число от 1 до 5 включительно.
- Одна бронь допускает одну оценку; изменение оценки не поддерживается.
- Для `cancelled_by_client`, `cancelled_by_venue`, `confirmed` и `rated` шторка не открывается.
- Онлайн-комментарии и фотографии не входят в MVP.
- Offline блокирует submit и не создаёт queued-оценку.
- Значение звёзд доступно Screen Reader как «N из 5».

## 7. Acceptance Criteria

### AC-SCR-008-001 — Успешная оценка

**Связанные требования:** FR-010, BR-009, NFR-006

**Given** бронь имеет статус `completed` и ещё не оценена,
**When** Клиент выбирает значение от 1 до 5 и нажимает «Отправить оценку»,
**Then** приложение вызывает `POST /bookings/{id}/rating`, после HTTP 201 закрывает Bottom Sheet и обновляет статус записи.

### AC-SCR-008-002 — Недопустимый статус

**Связанные требования:** FR-010, BR-009, NFR-003

**Given** бронь активна, отменена или уже оценена,
**When** Клиент пытается открыть или отправить оценку,
**Then** Bottom Sheet не открывается либо API возвращает 400/409, приложение не создаёт вторую оценку и объясняет причину на `SCR-007`.

### AC-SCR-008-003 — Ошибка и Offline

**Связанные требования:** FR-010, NFR-005, NFR-003

**Given** API вернул 503/401 или сеть недоступна,
**When** Клиент находится в Bottom Sheet,
**Then** приложение не показывает ложный успех, блокирует повторную отправку до подключения/повторной авторизации и сохраняет выбранное значение для безопасного retry.
