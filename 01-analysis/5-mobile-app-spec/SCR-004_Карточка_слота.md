# SCR-004 — Карточка слота

## 1. Метаданные

| Поле | Значение |
|---|---|
| ID | `SCR-004` |
| Название | Карточка слота |
| Роль | Клиент |
| Тип | Детали тренировки |
| Маршрут | `slots/{id}` |
| Точка входа | Выбор карточки из `SCR-003` |
| Связанные требования | `BR-002`, `BR-006`, `BR-014`, `FR-002`, `FR-003`, `NFR-005`, `NFR-006`, `US-003`, `UC-002` |
| Версия | 1.0.0 |
| Приоритет | Must |

## 2. Цель и пользовательский сценарий

- Цель: показать всю информацию для решения о бронировании конкретного слота.
- Основной сценарий: Клиент открывает карточку, видит время, формат, инструктора, адрес, места и доступный прокат, затем переходит к `SCR-005`.
- Условия доступа: действует Bearer-токен; `slot_id` получен из расписания и является UUID.
- Результат: Клиент может оценить слот и начать оформление одной брони, если слот доступен.

Обязательные элементы:

- Время, формат, инструктора, адрес и свободные места.
- Блок доступности проката с тарифом и остатком.
- Статус слота и причину отмены, если она присутствует.
- CTA, который блокируется при 0 мест.
- Loading, Error, Offline и Forbidden-состояния.

## 4. Состояния экрана

| Состояние | Условие | Отображение | Действие клиента |
|---|---|---|---|
| Initial | Открыта карточка, детали ещё не загружены | Заголовок, Skeleton полей и CTA disabled | Дождаться ответа |
| Loading | Выполняется `GET /slots/{id}` | Skeleton с сохранением `slot_id` | Дождаться или вернуться |
| Success | API вернул HTTP 200 и слот доступен | Полная карточка, прокат и активное CTA | Нажать «Записаться» |
| Empty | API вернул слот, но `available_places = 0` | Информационный блок «Свободных мест нет», CTA disabled | Вернуться к расписанию |
| Error | API вернул 404, 401 или 503 | Сообщение с Retry; при 401 — вход | Повторить, вернуться или войти |
| Offline | Нет сети, но детали есть в кэше | Карточка с меткой «Данные могут быть неактуальны», CTA заблокирован до сети | Читать детали и обновиться позже |
| Forbidden | Токен истёк или слот недоступен текущему клиенту | Показывает безопасное состояние, не раскрывая внутренние данные | Вернуться или войти |

## 5. Взаимодействие с API

| Вызов | Endpoint / метод | Назначение | Перед вызовом | Обработка ответа | Обработка ошибки |
|---|---|---|---|---|---|
| API-SLOT-002 | `GET /slots/{id}` | Получить детали, места и прокат | Bearer-токен; path `id` — UUID из расписания | `200 TrainingSlot`: заполнить карточку | `401`: переход на `SCR-001`; `404`: «Слот не найден» и назад; `503`: Retry |

Требования к обработке:

- Не переходить к бронированию из локального кэша без актуального ответа или явного статуса.
- При `available_places = 0` заблокировать CTA независимо от кэшированного состояния.
- Отдельно отображать прокат, где `is_active = true` и `available_quantity > 0`.
- При 401 очищать клиентский маршрут и не считать кэш авторизованным.
- При 404 вернуть к `SCR-003`, не создавая фиктивный слот.
- При сетевой ошибке сохранить только read-only кэш с меткой неактуальности.

## 6. Валидация и правила

- `id` — UUID, полученный из `GET /slots`.
- `starts_at` и `ends_at` — валидные даты, `starts_at < ends_at`.
- `capacity` — от 1 до 16, `available_places` — от 0 до `capacity`.
- Для новичкового формата backend может вернуть вместимость 8; UI не изменяет это значение.
- `status = cancelled` запрещает CTA и показывает `cancellation_reason`.
- Rental-опция с `available_quantity = 0` отображается как недоступная и не выбирается.
- Адрес и время не редактируются мобильным приложением.
- Все обязательные поля соответствуют `TrainingSlotSummary`.

## 7. Acceptance Criteria

### AC-SCR-004-001 — Полная карточка слота

**Связанные требования:** FR-003, BR-002, BR-014, NFR-006

**Given** Клиент выбирает слот из расписания,
**When** API возвращает HTTP 200,
**Then** экран показывает время, формат, инструктора, адрес, свободные места и варианты проката, а карточка помещается на ширине от 360 dp.

### AC-SCR-004-002 — Нулевой остаток

**Связанные требования:** FR-003, BR-004, BR-013

**Given** `available_places = 0` или `status = cancelled`,
**When** карточка отрисована,
**Then** CTA «Записаться» заблокирована, причина недоступности показана, а переход в `SCR-005` невозможен.

### AC-SCR-004-003 — Ошибка и Offline

**Связанные требования:** FR-003, NFR-005, NFR-006

**Given** API вернул 404/503 или сеть недоступна,
**When** Клиент открывает карточку,
**Then** приложение показывает Error с Retry либо кэш с меткой неактуальности и не принимает решение о свободном месте по устаревшим данным.
