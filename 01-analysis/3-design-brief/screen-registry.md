## 3. Границы экранов

| Экран | Вход | Основной результат | Ограничения |
|---|---|---|---|
| SCR-001 | Запуск приложения | Запрос SMS-кода | Нет доступа к персональным данным до верификации |
| SCR-002 | Валидный номер телефона | Bearer-токен и переход к расписанию | Код одноразовый; неверный код не меняет состояние сессии |
| SCR-003 | Успешная авторизация | Выбранный слот или пустое расписание | По умолчанию период 7 дней; есть фильтры даты, формата и инструктора |
| SCR-004 | Выбор слота | Переход к оформлению или состояние недоступности | Приложение только читает слот и не редактирует расписание |
| SCR-005 | Доступный слот | Подтверждённая бронь на одного клиента | Нет выбора количества людей и онлайн-оплаты |
| SCR-006 | Авторизованный клиент | Выбранная запись для действия | Показываются только брони текущего клиента |
| SCR-007 | Выбранная или push-linked бронь | Отмена, история или статус отмены скалодромом | Отмена доступна не позднее чем за 2 часа |
| SCR-008 | Завершённая неоценённая бронь | Оценка 1–5 звёзд | Не доступен для активных, отменённых и уже оценённых записей |

## 4. Трассируемость к качеству

| Экраны | NFR | Проверяемое поведение |
|---|---|---|
| SCR-003 | NFR-001, NFR-005, NFR-007 | Быстрый список, кэш с пометкой, Empty State без ложных слотов |
| SCR-004, SCR-006, SCR-007, SCR-008 | NFR-006 | Все действия доступны на ширине от 360 dp |
| SCR-005 | NFR-002, NFR-003, NFR-005 | Ограничение повторного submit, 409 без фантомной брони, блокировка без сети |
| SCR-007, SCR-008 | NFR-003, NFR-005 | Безопасные статусы, обновление после push и отсутствие повторной оценки |

## 5. Общие UI-правила

- Экраны с сетевыми данными содержат Loading, Success, Empty State, Error и Offline states.
- В `SCR-003` и `SCR-004` данные кэша маркируются как неактуальные.
- `SCR-005` показывает явную плашку «Оплата на месте» до и после подтверждения.
- `SCR-007` всегда различает «Отменена клиентом» и «Отменена скалодромом».
- `SCR-008` является Bottom Sheet поверх `SCR-007`, а не отдельным маршрутом расписания.
